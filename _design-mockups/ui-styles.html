项目简介

这是一份关于 Markdown 阅读器 的设计文档。本工具旨在替代 Windows 记事本，为 .md 文件提供更优雅的阅读体验。

核心功能

  1. 实时渲染 Markdown 语法（标题 / 列表 / 表格 / 代码块）
  2. 支持代码高亮，覆盖主流语言
  3. 中、英、日、韩、繁中 五语言界面
  4. 浅色 / 深色 主题一键切换
设计目标：审美高于记事本，体验直追 Notion。

代码示例

def render(md: str) -> str:
    return marked.parse(md)
